# Refleksjon

## Hva er JSON?

- JSON er en type fil som inneholder data som kan bli brukt for å gi en output eller bli brukt som ett lager for informasjon.

## Hvordan er JSON bygget opp?

- En JSON fil er bygget opp av variabler som identifiserer en verdi som kan bli hentet ut av f.eks en .JS eller .py kode.

## Hva var lett?

- Jeg syntes at det er ganske lett å forstå hva de forskjellige kommandoene og variablene gjør i både JSON filer og python osv.

## Hva var vanskelig?

- Jeg syntes det var litt utfordrene å få ut informasjonen på en effektiv måte fra JSON til en python kode, men jeg syntes det går ganske greit nå.

## Hva er forskjellen på en lokal JSON-fil og et API? 

### JSON-fil
- En JSON-fil er noe du selv lager eller som er lagret lokalt på maskinen din, denne gir ut informasjon direkte til prosjektet som spør om informasjonen.

 ### API
 - En API lager en bro fra ett nettsted og til ett prosjekt via URL og noen ganger med en token fra nettstedet for å "Logge inn".
